Multicam + audio switcher in Remotion

Two shots lined up on one timeline by their shared audio. Cut between them and choose the audio.

How it works

Everything happens inside the Remotion composition (src/Multicam.tsx); this page only embeds it with @remotion/player.

  • Line-up (automatic): scripts/sync.mjs cross-correlates the two clips’ audio and found that B started 9.78s before A (peak 4× stronger than any rival). That number lives in src/sync.ts; the composition places each clip in a <Sequence from=…> accordingly, so the picture and sound of both shots are aligned.
  • Cut list: a cuts prop ({at, shot, audio}) says which shot is visible and which audio is heard from each moment. Default: B until A begins, cut to A, back to B when A ends, with B’s audio throughout. Edit it live in Remotion Studio’s props panel.
  • Both clips always play, so cuts are instant: shot = opacity, audio = volume.
  • Buttons above temporarily override the cut list so you can audition any shot/audio combination.
  • Export: npm run render writes the edit to out/multicam.mp4; npm run studio opens Remotion Studio.
